# Testing Documentation Index

Welcome to the Integrated Water & Natural Resource Management Testing Documentation. This directory contains all testing artifacts, plans, reports, and procedures for our microservices.

## Scope
This documentation covers the functional, non-functional, integration, database, and UI testing of the project, including:
- `distribution-service`
- `water-resource-service`
- `quality_maintainance` (Water Quality application)
- API Gateway and UI
